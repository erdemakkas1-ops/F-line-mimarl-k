# F LINE Mimarlık & Mühendislik – web sitesi demosu

Statik site. Kurulum gerektirmez.

## GitHub Pages
Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save.

## Yapı
- `index.html` sayfa, `app.js` 3D deneyim (Three.js paketlenmiş)
- `a/` görseller, dokular ve 3D modeller; hangi dosyanın ne için kullanıldığı `asset-manifest.json` içinde

## Notlar
- Sitedeki villa kavramsal bir çalışmadır; gerçekleşmiş bir F LINE projesi değildir.
- İletişim formu demo durumundadır, mesaj göndermez.
- 3D modeller: Khronos glTF Sample Assets. Gökyüzü panoraması ve dokular: three.js örnek varlıkları.
